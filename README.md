# ⏳ Countdown Timer Web App

A simple Countdown Timer built using **HTML, CSS, and JavaScript**.  
This project allows users to start, pause, and reset a timer with a clean and minimal UI.

---

## 🚀 Features

- ⏱ Countdown timer functionality  
- ▶️ Start, ⏸ Pause, 🔄 Reset buttons  
- ⚡ Alert when time is up  
- 🖥 Simple and clean user interface  
- 📱 Beginner-friendly JavaScript project  

---

## 📁 Project Structure

```
timer-project/
│── index.html      # Main HTML file
│── style.css       # Styling file
│── script.js       # JavaScript functionality
```

---

## 🖥️ How to Run

1. Download or clone the repository  
2. Open the project folder  
3. Open `index.html` in any browser  
4. Use the buttons to control the timer  

---

## ⚙️ How It Works

- Timer starts from **10 seconds**
- **Start button** → begins countdown  
- **Pause button** → stops timer temporarily  
- **Reset button** → resets timer back to 10  
- When timer reaches **0**, an alert appears
